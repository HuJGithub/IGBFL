# IGBFL

## Introduction

This repository contains the source code for **IGBFL**, a feature-selection-based fault localization approach. IGBFL addresses the high dimensionality of statement coverage data generated by program test suites by selecting informative statements for fault localization.

## Environment

- **Operating system:** Linux
- **Python dependencies:**

  | Package | Version |
  | --- | --- |
  | `pandas` | `0.25.1` |
  | `chardet` | `3.0.4` |
  | `numpy` | `1.16.5` |
  | `torch` | `1.9.0` |

Install the listed dependencies with:

```bash
pip install pandas==0.25.1 chardet==3.0.4 numpy==1.16.5 torch==1.9.0
```

> **Note:** The dependencies above are the versions used by the project. Depending on your Python version and platform, a compatible environment may be required.

## Usage

Run the program from the repository root with the following command:

```bash
python run.py -d <dataset> -p <program> -i <bug_id> -m <method> -e <experiment>
```

### Required Arguments

| Argument | Description | Example values |
| --- | --- | --- |
| `-d` | Dataset | `d4j`, `manybugs`, `SIR` |
| `-p` | Program name | `Chart`, `Closure`, `Time`, `Lang`, `motivation` |
| `-i` | Bug identifier | `1`, `2`, `artificial_bug` |
| `-m` | Fault localization method | `dstar`, `ochiai`, `barinel`, `MLP-FL`, `GP02` |
| `-e` | Experiment type | `origin`, `resampling`, `undersampling`, `fs` |

### Example Commands

The following commands use the repository's artificial motivation example to demonstrate the different experiment modes.

#### 1. Original Method

```bash
python run.py -d manybugs -p motivation -i artificial_bug -m GP02 -e origin
```

Example result:

```text
motivation-artificial_bug   GP02   12
```

#### 2. Resampling

```bash
python run.py -d manybugs -p motivation -i artificial_bug -m GP02 -e resampling
```

Example result:

```text
motivation-artificial_bug   GP02   7
```

#### 3. Undersampling

```bash
python run.py -d manybugs -p motivation -i artificial_bug -m GP02 -e undersampling
```

Example result:

```text
motivation-artificial_bug   GP02   7
```

#### 4. Feature Selection

```bash
python run.py -d manybugs -p motivation -i artificial_bug -m GP02 -e fs
```

Example result:

```text
motivation-artificial_bug   GP02   9
```

### Output Format

The results are stored as text files in the `results/` directory. Each example output record contains the program and bug identifier, the fault localization method, and the resulting fault rank:

```text
<program>-<bug_id>   <method>   <rank>
```

For example:

```text
motivation-artificial_bug   GP02   12
```

Here, `motivation-artificial_bug` identifies the program and bug, `GP02` is the fault localization method, and `12` is the rank at which the first faulty statement is located in this example.

> **Note:** The commands above preserve the original repository's argument values. In particular, the motivation example uses `-d manybugs` although its data is shown under `data/motivation/` in the directory listing. Check the dataset-selection logic in `run.py` and the data loaders if this command does not resolve the example dataset in your checkout.
